# Norwegian Wood Sunrise

An Omarchy theme featuring a warm, dark palette and the `Trolltjonn_sunset` background.

## Install

Install the repository with Omarchy:

```sh
omarchy theme install <git-repository-url>
```

Omarchy installs the theme and applies it. To install from a local checkout, copy this directory to `~/.config/omarchy/themes/norwegian-wood-sunrise`, then select it with `omarchy-theme-set norwegian-wood-sunrise`.
